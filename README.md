2D game engine/app framework thing, written using as little (debatable) third-party libraries as possible, as a learning project.

Libraries:
GLFW for OpenGL context creation.
GLAD for loading OpenGL functions.
PortAudio for audio I/O.
stb_image for loading textures.
stb_image_write for creating a texture atlas.
stb_vorbis for loading ".ogg" audio files.
