2D game engine/app framework thing, written using as little (debatable) third-party libraries as possible, as a learning project.<br />

Libraries:<br />
GLFW for OpenGL context creation.<br />
GLAD for loading OpenGL functions.<br />
PortAudio for audio I/O.<br />
stb_image for loading textures.<br />
stb_image_write for creating a texture atlas.<br />
stb_vorbis for loading ".ogg" audio files.<br />
